# مجموعة تالانس | TALANS GROUP

الموقع الرسمي التعريفي لمجموعة تالانس — موقع مؤسسي تفاعلي بالعربية مع دعم RTL كامل.

---

## التشغيل

```bash
npm install
npm run dev
```

الأوامر المتاحة:

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | تشغيل خادم التطوير |
| `npm run build` | فحص الأنواع + بناء نسخة الإنتاج في `dist/` |
| `npm run build:single` | بناء نسخة **ملف واحد مستقل** (انظر أدناه) |
| `npm run preview` | معاينة نسخة الإنتاج محليًا |
| `npm run typecheck` | فحص أخطاء TypeScript فقط |

---

## نسخة الملف الواحد المستقل

```bash
npm run build:single
```

تُنتج ملفين داخل `dist/`:

| الملف | الاستخدام |
| --- | --- |
| `talans-standalone.html` | **ملف كامل** — انقر عليه نقرًا مزدوجًا ليفتح في المتصفح مباشرة |
| `talans-embed.html` | نسخة بدون وسوم `html/head/body` — للتضمين داخل صفحة مستضيفة |

كل شيء مدمج داخل الملف: JavaScript، CSS، الشعار، **والخطوط العربية واللاتينية**.
لا يحتاج خادمًا ولا اتصالًا بالإنترنت ولا `npm install` — يعمل حتى بلا شبكة،
ويمكن إرساله بالبريد أو رفعه على أي استضافة كملف واحد.

> الخطوط تُجلب مرة واحدة عند أول بناء وتُخزَّن في `.cache/` (مستثنى من Git).
> لتحديثها: `node scripts/embed-fonts.mjs --refresh`.
> إذا لم يتوفر اتصال ولا نسخة مخزّنة، يكمل البناء ويستخدم خطوط النظام مع تنبيه.

## ✏️ تعديل المحتوى

كل النصوص والبيانات منفصلة عن الواجهة، ولا تحتاج لتعديل أي Component.

| ما تريد تعديله | الملف |
| --- | --- |
| الشعار، بيانات التواصل، روابط القائمة، نصوص الأقسام، الأرقام | `src/data/site.ts` |
| الشركات والعلامات التجارية | `src/data/companies.ts` |
| المشاريع | `src/data/projects.ts` |
| مجالات العمل | `src/data/services.ts` |
| محاور الاستثمار ورحلة الاستثمار | `src/data/investment.ts` |
| عناصر شريط شبكة الأعمال | `src/data/marquee.ts` |
| حقول النماذج | `src/data/forms.ts` |

### استبدال الشعار

ضع ملف الشعار الرسمي في `public/brand/` ثم عدّل `BRAND.markSrc` في `src/data/site.ts`.
إذا كان الملف Lockup كاملًا (رمز + اسم)، اضبط `BRAND.showWordmark: false`.
التفاصيل في `public/brand/README.md`.

> ⚠️ الشعار الحالي `public/brand/talans-mark.svg` **مؤقت** ويجب استبداله بالشعار الرسمي.

### استبدال الصور

الصور الحالية عناصر بصرية تجريدية مولّدة برمجيًا (`src/data/visuals.ts`) — بدون أي طلبات خارجية.
لاستبدالها بصور حقيقية: ضع الصور في `public/media/` وغيّر قيمة `image` في ملف البيانات:

```ts
// قبل
image: abstractVisual({ seed: 11, variant: 'blocks' }),
// بعد
image: '/media/company-one.jpg',
```

### ربط النماذج بخادم

النماذج تعمل بالكامل (تحقق من المدخلات + حالة إرسال + رسالة نجاح)، لكن لا يوجد Backend.
نقطة الربط الوحيدة هي دالة `submitForm` في `src/lib/submitForm.ts` — استبدل محتواها بطلب `fetch`
إلى نقطة النهاية لديك. حاليًا يمكن للمستخدم إرسال نسخة من البيانات عبر واتساب بعد الإرسال.

### بيانات تحتاج تأكيدًا

| العنصر | القيمة الحالية | الحالة |
| --- | --- | --- |
| الشعار | `public/brand/talans-mark.svg` | مؤقت — يُستبدل بالرسمي |
| البريد الإلكتروني | `info@talansgroup.com` | مبدئي — قابل للتعديل من `site.ts` |
| أسماء الشركات | `Company One … Eight` | أسماء مؤقتة |
| روابط المشاريع | غير محددة | زر «استكشف المشروع» معطّل حتى تُضاف `url` |
| الجوال / واتساب | `050-826-0161` / `966508260161` | مؤكّد |

## الخطوط

الهوية تستخدم خط **Kanit** كما هو مطلوب. Kanit لا يحتوي على محارف عربية،
لذلك تم إقرانه بـ **IBM Plex Sans Arabic** للنصوص العربية، مع بقاء Kanit
للأحرف اللاتينية والأرقام (عبر الصنف `.font-latin`). الخطان يُحمَّلان من Google Fonts
في `index.html`.

## ملاحظات تقنية

- الموقع بالكامل `lang="ar"` و `dir="rtl"`، ويستخدم خصائص CSS المنطقية (`ms-` / `me-` / `start-` / `end-`).
- تأثير تكدّس بطاقات المشاريع (Sticky Stacking) يعمل على الشاشات الكبيرة فقط؛
  على الجوال تُعرض البطاقات في تدفّق عادي منعًا لتجاوز المحتوى ارتفاع الشاشة.
- جميع التأثيرات الثقيلة (المغناطيس، حركة المؤشر) تُعطَّل تلقائيًا على أجهزة اللمس
  وعند تفعيل `prefers-reduced-motion`.
- الصور تُحمَّل بشكل كسول (`loading="lazy"`) ومستمعو التمرير `passive` ويتم تنظيفهم.
- لا يوجد تمرير أفقي على أي مقاس شاشة.

## نسخة الـ Artifact — ملف واحد (`TalansGroup.jsx`)

`TalansGroup.jsx` في جذر المستودع هو الموقع كاملاً في **ملف React واحد**، مُعدّ للصق المباشر
داخل Claude Artifact (لا Vite ولا `src/` ولا خطوة بناء).

- المكتبات المستخدمة: `react`، `framer-motion`، `lucide-react`، و Tailwind (classes أساسية + arbitrary values).
  إن كانت بيئتك تستخدم حزمة `motion` الجديدة، غيّر سطر الاستيراد إلى `from 'motion/react'` — بقية الكود نفسه.
- لا `localStorage` ولا `sessionStorage` — الحالة عبر `useState` فقط.
- كل المحتوى القابل للتعديل في ثوابت أعلى الملف: `LOGO_SRC`، `SITE`، `NAV_LINKS`، `ABOUT`،
  `STATS`، `SECTORS`، `INVESTMENT`، `SERVICES`، `PROJECTS`، `CONTACT`، `FORMS`.
- اللوجو نصّي بخط ثمانية + نجمة SVG. لعرض صورة اللوجو بدلاً منه: اضبط `LOGO_SRC` على رابط الصورة.
- النماذج بلا backend: كل نموذج ينتهي بزرّي إرسال — عبر البريد (`mailto:`) أو عبر واتساب (`wa.me`)،
  ويكتمل الإرسال من تطبيق الزائر.
- الثيم: أخضر زمردي على خلفية بيضاء — `#009e52` / `#1d6b38` / `#144b27` / `#008947`.

> ملاحظة: الكشف النصي مع التمرير (`AnimatedText`) يعمل **كلمةً كلمة** لا حرفاً حرفاً،
> لأن فصل الأحرف العربية في عناصر مستقلة يكسر اتصال الحروف ويشوّه الخط.

المجلد `src/` يحتفظ بنسخة Vite متعددة الملفات من مرحلة سابقة؛ نسخة الـ Artifact مستقلة عنها تماماً.

```bash

```
